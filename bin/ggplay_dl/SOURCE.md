# ggplay_dl

Vendored from [FiorenMas/Revanced-And-Revanced-Extended-Non-Root]
(https://github.com/FiorenMas/Revanced-And-Revanced-Extended-Non-Root),
`src/build/helper/ggplay_dl/`, which in turn rewrote it from
[AuroraStore](https://gitlab.com/AuroraOSS/AuroraStore).

Both are GPL-3.0, same as this repository.

Downloads the current Play release of a package using an anonymous account
from Aurora's dispenser, so no Google account is needed. Play only ever
serves the current version, so `dl_gplay` refuses pinned builds.
